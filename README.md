# Smart Reply AI (Android)

نسخة أولية لتوليد ردود مقترحة على تعليقات Facebook.

## الوظائف الحالية
- إدخال رابط منشور يختاره المستخدم.
- لصق نص التعليق يدويًا.
- إرسال النص إلى خادم ذكاء اصطناعي عبر HTTPS.
- عرض الرد المقترح ونسخه لمراجعته ونشره يدويًا.

## حدود مهمة
هذا الإصدار لا يسجل الدخول إلى Facebook، ولا يجلب تعليقات الحساب الشخصي تلقائيًا، ولا ينشر الردود تلقائيًا. لا تضع مفتاح API داخل التطبيق. يلزم خادم HTTPS خاص يحتفظ بالمفتاح ويعيد JSON يحتوي على الحقل `reply`.

## البناء
يتم البناء عبر GitHub Actions باستخدام JDK 17 وGradle 8.9. ملف APK الناتج هو نسخة Debug للتجربة الأولية، وليس إصدارًا منشورًا على Google Play.
